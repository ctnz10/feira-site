PUGLIA — SITE DA FEIRA CULTURAL
================================

COMO ABRIR
1. Extraia o arquivo ZIP para uma pasta do computador.
2. Abra o VS Code.
3. Clique em Arquivo > Abrir Pasta e escolha a pasta "puglia_site".
4. Abra o arquivo index.html.
5. Para visualizar, instale a extensão "Live Server" no VS Code (se ainda não tiver).
6. Clique com o botão direito em index.html e escolha "Open with Live Server".

COMO COLOCAR O VÍDEO DO GRUPO
1. Dentro da pasta do projeto, crie uma pasta chamada: video
2. Coloque o vídeo dentro dela.
3. Renomeie o arquivo para: puglia.mp4
4. O caminho final deve ficar assim: video/puglia.mp4
5. Atualize o site no navegador.

IMPORTANTE
- O site usa fotografias de exemplo carregadas da internet; elas precisam de conexão.
- As fotografias são ilustrativas e podem não retratar exatamente cada lugar. Para a versão final, use fotos de Puglia e confira as permissões de uso.
- As animações GSAP e as fontes também carregam da internet.
- O site é responsivo para celular e computador.
- Se as animações não carregarem, o conteúdo principal continua visível.
- Para personalizar os textos, abra index.html e altere os parágrafos e títulos.
